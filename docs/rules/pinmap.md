# Pinmap Rules

- [pinmap.collision](pinmap.collision.md): Checks pinmap files for duplicate pin and net assignments.
- [pinmap.net-label](pinmap.net-label.md): Checks pinmap net names against schematic labels visible to firmware integration.
- [pinmap.unmapped-pin](pinmap.unmapped-pin.md): Checks connected schematic pins for matching pinmap entries.
- [pinmap.verify](pinmap.verify.md): Checks configured pinmap nets against parsed schematic net labels.
