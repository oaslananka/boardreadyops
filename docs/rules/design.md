# Design Rules

- [design.board-outline](design.board-outline.md): Checks that the PCB Edge.Cuts outline is present and closes into a board boundary.
- [design.copper-balance](design.copper-balance.md): Checks filled copper coverage on PCB layers against the configured minimum.
- [design.unique-references](design.unique-references.md): Flags board footprints that share a reference designator.
