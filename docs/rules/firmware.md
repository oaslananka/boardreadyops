# Firmware Rules

- [firmware.arduino-pin-contract](firmware.arduino-pin-contract.md): Checks an Arduino/C `#define` firmware pin header against the BoardReadyOps pinmap.
- [firmware.dependency-identification](firmware.dependency-identification.md): Reports how many ESP-IDF dependencies have an identifier a vulnerability database indexes.
- [firmware.esp-idf-pin-contract](firmware.esp-idf-pin-contract.md): Checks an ESP-IDF firmware pin contract YAML against the BoardReadyOps pinmap.
- [firmware.platformio-pin-contract](firmware.platformio-pin-contract.md): Checks a PlatformIO-style firmware pin contract against the BoardReadyOps pinmap.
- [firmware.stm32cubemx-pin-contract](firmware.stm32cubemx-pin-contract.md): Parses a STM32CubeMX `.ioc` project file and checks GPIO labels against the BoardReadyOps pinmap.
- [firmware.zephyr-pin-contract](firmware.zephyr-pin-contract.md): Checks a Zephyr firmware pin contract YAML against the BoardReadyOps pinmap.
